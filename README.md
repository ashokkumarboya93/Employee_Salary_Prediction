# 🚀 Employee Salary Prediction

## 🌟 Overview

This project leverages machine learning to predict employee salaries based on historical data and relevant features like experience, education, skill set, and more. The model can assist in benchmarking salaries, identifying outliers, and promoting fair compensation practices.

---

## ✨ Features

- Predict salaries based on multiple factors
- Clean and preprocess input data automatically
- Visualize relationships and model performance
- Export predictions to CSV or Excel
- Easy to use interface (CLI and notebook)
- High accuracy with flexible model selection

---

## 📦 Installation

1. **Clone the repo:**
   ```bash
   git clone https://github.com/ashokkumarboya93/Employee_Salary_Prediction.git
   cd Employee_Salary_Prediction
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

---

## ▶️ Usage

- **Jupyter Notebook:**  
  Run `Employee_Salary_Prediction.ipynb` for step-by-step interactive exploration.

- **Command Line:**  
  ```bash
  python predict_salary.py --input employee_data.csv
  ```

- **Customize:**  
  Modify configuration in `config.yaml` for advanced options.
